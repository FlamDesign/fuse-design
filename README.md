# Flam UI kit

shadcn/ui component reference and sample screens for the Flam platform.
Vite + React 19 + Tailwind v4, Radix base, Rhea style, Hugeicons, Rethink Sans, shadcn/typeset at 16px.

## Run

```bash
npm install
npm run dev          # local reference site
npm run build        # production build with hash routing
npm run build:hosted # few-file build used for the hosted Claude artifact
```

`npm run build -- --mode artifact --outDir dist-artifact` builds the hosted variant (in-memory routing).

## Theme

All tokens live in `src/index.css` under `:root` and `.dark`. Change values only; the names are what every
component reads. `THEME-CHANGES.md` lists each value against the shadcn default.

## Structure

- `src/components/ui` · the 63 shadcn components
- `src/registry.ts` · title, description and exports for each component page
- `src/pages/docs` · components index and the per-component page (preview, code, installation, usage)
- `src/pages/components` · the preview sources, grouped by category
- `src/pages/apps` · sample screens: dashboard, campaigns, creative editor, flow builder, asset library, inbox, assistant, settings
- `src/layouts/app-layout.tsx` · shell, `src/nav.ts` · sample screen navigation

## Edits to generated components

- `sonner.tsx` reads the local theme provider
- `spinner.tsx` prop type fix
- `slider.tsx` labels each thumb
- `combobox.tsx` labels the trigger button
- `sidebar.tsx` and `theme-provider.tsx` tolerate blocked cookies and storage
- `carousel.tsx`, `use-mobile.ts` lint fixes

## AI Elements

The 21 AI Elements patterns from shadcn/ui, plus the `shimmer` and `scroll-fade` utilities and the `@shadcn/helpers` chat helpers, live under `/ai`.

- Pattern sources are in `src/examples/ai`, generated from the shadcn/ui repo by `tools/gen_ai.py` (paths rewritten, Lucide icons mapped to Hugeicons).
- They are compositions of components already in `src/components/ui`. There is no extra package to install for the patterns themselves.
- Demos and the Assistant screen run on the Vercel AI SDK (`ai`, `@ai-sdk/react`) with scripted conversations from `@shadcn/helpers/ai-sdk`, so no model or API key is needed.
- `src/components/markdown.tsx` renders streamed replies with Streamdown and the kit's typeset styles.

## Component examples

Every component page ends with an Examples section holding the variations from the shadcn/ui docs: 440 examples across 63 components.

- Sources are in `src/examples/ui`, generated by `tools/gen_ui.py` from the shadcn/ui repo. Lucide and Tabler icons are mapped to Hugeicons, `next/link` and `next/image` become plain elements, and remote photos are replaced with local placeholders in `public/`.
- The folder is excluded from lint because it is upstream code. Do not edit it by hand; rerun the generator.
- Left out: right-to-left examples, the full-page sidebar block, and the TanStack Table v9 data table demo (the kit pins v8 and has its own data table).

## Regenerating upstream examples

`tools/gen_ui.py` and `tools/gen_ai.py` rebuild `src/examples` and the two generated registries from a clone of `shadcn-ui/ui`. Point `SHADCN_UI_V4` at its `apps/v4` folder, run the script with Python 3, then run Prettier on `src/examples`.
